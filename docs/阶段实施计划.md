# 阶段实施计划

本计划按技术验收推进，当前状态以进度看板、project_status.json及实际证据为准。

## 项目交付

SO101根据顶部/腕部图像、本体状态和指令完成牙刷入杯；基于完整pi05_base进行expert-only微调，并验证模型服务、本地执行与可复现真实评测。

## 里程碑与验收

| 阶段 | 工作 | 验收 |
|---|---|---|
| G0 | 环境、主从臂、相机、标定与任务可行性 | 实际设备、动作/图像契约和遥操作证据 |
| G1 | 10～20条试采，先检查3～5条 | 视频、数值、时序、指令与数据QA；保留排除原因 |
| G2 | 短训练、参数审计、保存重载、模型服务与首次真实闭环 | 真实batch更新、工件可独立加载、接口及真机执行证据 |
| G3 | 起点80～120条高质量数据、整组划分 | 冻结版本、分组清单、仅来自训练集的统计 |
| G4 | 主训练及checkpoint选择 | 实测吞吐/显存、恢复工件、处理器与模型选择依据 |
| G5 | 部署调试与一次主要问题修正 | 延迟、动作队列、失败与修改记录 |
| G6 | 主模型40次协议化测试 | 全部尝试、失败、系统中断、视频和固定协议 |
| G7 | 报告、演示与复现材料 | 数据/模型说明、配置、结果表与限制 |

## 数据与模型规则

- 固定top/wrist名称、镜像方向、六维顺序、单位、夹爪和采样关系；候选设置不能冒充实测。
- 两支牙刷、两个杯子，红/蓝×左/右四条件是同一抓放技能；必要时缩减为同一牙刷左右两条件。
- 完整预训练起点，实际审计expert与投影参数；选择训练episode不等于重算train-only统计。
- 先做Real-only。仿真是可选支线，先对齐契约和统计，再安排独立Sim+Real对照，不把仿真成功率当真实结果。
- 正式测试与模型开发隔离；40次主评测保留所有系统结果。

## 计算资源与缩减

本地开发/采集，训练使用已核验的云GPU；先做短验证并记录实际单步时间、峰值显存与工件持久化，再决定长运行设置。推理卡、网络、费用和释放条件按实际会话记录，不预先承诺训练时长或费用。

资源受限时先暂停可选仿真和额外对照，保留一个主模型、语言配对及真实评测；四条件不稳可收缩为两条件，双相机不稳须在正式采集前冻结新的接口，不能静默混用。
