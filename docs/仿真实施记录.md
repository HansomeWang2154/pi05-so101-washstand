更新：2026-10-17。用户本次明确要求开始实现仿真与专家数据生成；据此提前启动可选支线。G0～G7真机状态保持原样，未运行训练、云实例或真实机械臂。

## 当前实现

采用MuJoCo 3.8.1、固定来源SO101模型、两个自由刚体牙刷和两个自由空腔杯。只有六个机器人执行器，没有物体执行器或抓取绑定。杯子由底盘和24段壁构成；牙刷由柄、刷头与外观刷毛构成。

原型物体尺寸和安装位置尚未对实物测量：牙刷质量16g、杯内径80mm/高76mm/质量200g；刷中心约(0.17,±0.06)m，杯中心约(0.31,±0.13)m。顶视图左对应世界+Y。相机原型320×240 RGB，控制30Hz，每周期20个1/600s物理子步，单位为原始模型弧度。

专家使用独立规划状态求受约束位姿；真实执行只发送关节目标。流程为接近、闭合、双指/试抬检查、抬升同时转向、杯上方、插入、松爪、撤离和稳定。独立检查器要求柄段进正确杯、杯真实支撑、机器人不再接触、杯未翻倒和连续至少2秒低速稳定。

## 代码阅读顺序

| 文件 | 负责什么 | 关键边界 |
|---|---|---|
| `sim/washstand/scene_config.json` | 物体尺寸、质量、布局、控制与渲染参数 | 当前为nominal值，尚未测量实物 |
| `sim/washstand/scene.py` | 基于固定SO101资产构建MJCF场景 | 杯壁/杯底真实碰撞，牙刷/杯均为自由体 |
| `sim/washstand/env.py` | 初始化、按关节名读写、子步积分、双相机与完整快照 | 只驱动机器人六个关节；每子步监测穿透峰值 |
| `sim/washstand/kinematics.py` | 在独立规划状态上求受约束位姿 | 不可达就失败，不修改执行中的物体状态 |
| `sim/washstand/expert.py` | 基于真值的状态机专家、平滑关节目标和阶段检查 | 特权状态只用于专家，尚无视觉策略推理 |
| `sim/washstand/validators.py` | 读几何、接触力、速度和错误历史，独立判断成功 | 不依赖专家done标志；检查两杯并记住终止错误 |
| `sim/washstand/recording.py` | `O_t/A_t`、完整物理状态、诊断和双视频 | 在推进物理前采样，失败/未完成记录保留 |
| `sim/washstand/generate.py` | 多指令、同初态分组、尝试清单和录制恢复 | 默认拒绝覆盖；resume校验参数、归档中断 |
| `sim/washstand/replay.py` | 从保存初态只执行已保存动作 | 不调用专家；重新比较观测/物理状态/时间及成功 |
| `sim/washstand/export_lerobot.py` | 合格数据写入LeRobot v3并finalize | 不上传；保留每条录制版本和校验版本证据 |
| `sim/washstand/inspect_dataset.py` | 新进程读取全量数据、检查动作窗口并生成预览 | 不加载π₀.₅，不代表模型batch或训练通过 |

阅读时沿着 `generate → env/expert → recorder → replay → exporter → inspector` 走一遍，再看检查器的反例测试，可区分“专家说完成”“物理成功”“数据完整”和“模型已能训练”四个层次。

## 调试中确认的设计修正

- 原杯布局离刷头抓点太近，腕相机外壳与杯壁发生约14mm几何穿插。重新分开抓取区与放置区后，红/蓝刷都能双指接触抬起。
- 朝下姿态不能直接竖直抬到高处：受五关节结构及腕关节范围限制。改为低位试抬，再沿连续位姿抬升和转向。
- 抓点x=0.047m靠近刷头，会在转向时滑脱。12组抓点/闭合量检查中，抓点x=0.035m、夹爪目标-0.15rad通过完整流程；未通过提高摩擦或绑定解决。
- 四种指令在固定布局下各一次完整物理流程成功。这是开发调试检查，不是随机任务成功率或sim-to-real结果。
- 运行缓存默认位置在当前工具中只读；LeRobot重读显式使用项目outputs下缓存，未改全局环境。
- 图形后端为Mesa llvmpipe CPU软件渲染。10次双路320×240小测：默认3.334s；关闭阴影/反射0.932s。该数字不含物理、编码/校验，不代表4060硬件性能。

原始排查证据位于本地 `outputs/sim/washstand_checks/`；大文件不进入Git，以上结论与代码版本关联保存。

## 数据合格门槛

逐次尝试保存metadata、完整初态、实际控制目标、观测状态、qpos/qvel、阶段、诊断和双视频。失败保留且不可直接导出。成功再从完整初态只回放控制目标，逐帧核对状态、qpos/qvel和时间，并重新检查最终物理成功。

初始实际布局相同的变体共享哈希分组，不按seed伪造不同布局；同初态换指令和同轨迹重渲染不能跨训练/验证。导出前重新验证视频解码、帧数、时间戳、数值和关节顺序；导出后从新进程读取LeRobot并与原始state/action比对。

当前仿真使用原始弧度和原型相机，**真实接口映射、真实相机外参和跨域统计未验证**。数据标记 `so101_sim`、`real_contract_verified=false`、`training_eligible=false`；它可以验证仿真数据管线，不能直接宣称联合训练准备完成。

## 数据生成与检查结果

固定布局smoke四条共2436帧、81.2秒模拟动作，全部物理/回放、LeRobot导出和新进程读取通过；加强后的双相机同帧图像比对共4872张也通过。该批开发中录制，metadata如实保留dirty=true，不作为冻结版本数据。

正式原型`nominal_jitter_v1_20261017`已完成20条，每种指令5条，共12,177帧、24,354张RGB、405.9秒模拟动作。5组布局、±2mm位置微扰；独立物理/控制回放全通过。前14条在`local-revision-002`录制，后6条在恢复修复`local-revision-003`录制，均为干净工作区。

一次SIGTERM中断保留原始半条，恢复后共20条合格、1条中断、21次执行；信号原因未知。导出接受20条、拒绝中断半条；新进程全量读取、数值比对、24,354张同帧图像相似度、100个边界窗口与CPU DataLoader batch通过。已审查200张双视角阶段关键帧，未手动逐帧观看全部视频。

当前检查：普通39项、仿真48项均通过；标准库模式39项中10项可选依赖测试跳过，其余通过。配置结构合法，真实设备和数据ID未填齐为预期状态。最大接触穿透3.542mm，低于6mm阈值。

分组清单为16条train / 4条validation；当前LeRobot统计来自全部20条，不能作为train-only统计。真实接口/相机未对齐，未运行模型/训练/云实例/真实机械臂。具体分布、图像误差、源代码与证据哈希、路径和限制见 [数据卡](数据卡_仿真原型v1.md) 与 [版本验收摘要](../environment/simulation-v1-summary.json)。
